# ⚡ eBay Arbitrage Hunter（eBay輸出・国内仕入れ自動監視システム）

国内フリマ・EC（メルカリ・ヤフオク等）をバックグラウンドで常時監視し、**「eBay販売相場より2割以上安い（または設定した利益基準を満たす）新着出品」**を自動検知して、商品写真・価格・見込み利益・購入直行リンク付きで即時通知するシステムです。

---

## 🌟 主な機能

1. **eBay相場連動 ＆ 2割安自動判定**
   - eBay相場価格（USD）を入力するだけで、最新為替レート（USD/JPY）をもとに「20%OFF仕入れ上限価格」を自動算出。
   - eBay販売手数料（約14.5%）＋国際送料を考慮した「実質見込み純利益」を自動試算。

2. **写真・利益つきリッチ通知（Discord Webhook）**
   - 出品写真（サムネイル）、出品価格、eBay相場、割引率、見込み利益、出品状態をEmbedカードでスマホ/PCに即時通知。
   - 通知内の「購入する」リンクから1タップで出品ページへ直行。

3. **PCアラート音 ＆ ポップアップ通知**
   - Web画面を開いておくだけで、新着出品検知時にブラウザから「ピロリン♪」とアラート音が鳴り、即座に気付けます。

4. **スマート除外フィルター（地雷・ゴミ出品の自動排除）**
   - 「ジャンク」「故障」「部品取り」「箱のみ」「写真のみ」などの不要な出品を自動で排除。

5. **洗練されたWebダッシュボード**
   - 監視商品の追加・削除・即時チェック
   - 過去の検知アイテムフィード・写真一覧・利益順ソート

6. **ランニングコスト 0円**
   - 有料APIや外部プロキシ契約なしで、ご自身のPC上で完全無料で永続動作。

## 🚀 使い方・起動方法（Windows）

### 1. ワンクリック起動
フォルダ内の **`run.bat`** をダブルクリックするだけです。
自動で必要なライブラリがセットアップされ、ブラウザで管理画面（`http://127.0.0.1:8000`）が開きます。

### 2. コマンドラインから起動する場合
```bash
# 依存ライブラリのインストール
pip install -r requirements.txt

# バックエンドサーバー起動
cd backend
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```
ブラウザで `http://127.0.0.1:8000` を開きます。

## 📱 Discord通知の設定方法

1. Discordの任意のサーバーで「チャンネルの編集」→「連携」→「ウェブフックを作成」
2. 発行された「ウェブフックURL」をコピー
3. 本システムのWeb画面の「**⚙️ 設定 & 通知連携**」タブを開く
4. Webhook URLを貼り付けて「**💾 設定を保存**」をクリック
5. 「**📨 テスト通知を送信**」ボタンを押してDiscordに通知が届けば完了です！
